# .github

Общие настройки для всех репозиториев `kreo-it-studio`: шаблоны issue и pull request, правила работы с кодом и политика безопасности. GitHub подставляет их в репозитории, где нет собственных файлов.

- `.github/ISSUE_TEMPLATE/` — шаблоны багов и задач
- `.github/PULL_REQUEST_TEMPLATE.md` — шаблон PR
- `CONTRIBUTING.md` — ветки, коммиты, PR, секреты, именование
- `SECURITY.md` — как сообщать об уязвимостях
